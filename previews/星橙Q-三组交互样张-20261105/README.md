## 当前效果

- 首页最多5只小伙伴，右上大Q独立保留。基础圆团常驻，其他展示位从已有伙伴中选择；保存后恢复原选择，取消不改变阵容，未获得的不能选，第6只会提示先取消一只。
- 已收藏但展示位已满的新伙伴留在收藏中，不挤掉原阵容、不增加第6只。欢迎过程中改变阵容，先自然收尾再调整；刷新后仍恢复该决定。
- 11种形状、13套配色直接来自当前小程序avatar-catalog与avatar模块。奶油白沿用确认的墨黑眼、暖棕星；独立外观入口不再使用临时替身形状。
- 首页不另设颜色选择。每种形状从profile.avatarColors读取自己的配色，profile.avatarColor仅兼容当前个人头像。旧账号当前形状保留原色，其他未设置的形状默认橙色；右上主形象保留品牌橙。框外的形状、配色与保存按钮模拟真实形象页已成功保存的结果，未保存的选择不影响首页。
- 不同轮廓保留各自的五官与星位；使用实际轮廓确定脚底与承重点，叠跳、压缩和离地衔接连续。三段主互动及六段日常保留。
- 小伙伴保持小尺寸与低占高，选伙伴入口在原平台内，不增加题目上方的高度。390框内平台仍高52px，收紧后的空白约8px，题卡约从316px处开始。
- 加载保留两颗轻盈星点与8秒柔和循环，准备好即显示首页；失败保留重试。
- 大Q进入时播放完整开场，已有开场持续轮换并保存上一次记录；刷新不回到固定第一段，避开刚播放过的剧情。可见安静停留60–70秒后，等待小Q自然收尾再偶尔开演。切页接续、答题简短回应、欢迎队列和小Q轻缓活动沿用。
- 选择弹层打开时直接隐藏画布与后备图，并暂停场景时钟；关闭后从原进度继续。保留主对话对原生obscured状态、普通反馈、补签弹层和题目结果反馈的处理。

## 手机与操作

固定390×844、375×667、320×740微信手机框，采用现行小程序字体、间距、题卡、品牌与四导航素材，框内滚动。可验证大字体与减少动态。

从首页“选伙伴”选择并保存。演示控制中可模拟集齐11种、解锁、欢迎、保存失败、已保存配色及九段互动；只修改本预览的本地模拟收藏。

## 资源与接入边界

sync-companion-assets.cjs只读提取现行小程序的avatar-catalog.js与avatar.js，生成companion-assets.js，包含来源指纹；--check验证未过期。形状母版、确认稿与奖励规则不在本轮重新设计。

companion-appearance.js负责动画的轮廓绘制、落地边界与实际头像同源展示。home-companions.js管理本地展示名单及已保存配色。app.js保留分开的可见性时钟和欢迎队列。

将来接入首页伙伴时，读取growthGet/profile.avatarColors及现行解锁cards；只在形象页成功保存后同步对应形状的颜色。展示名单需按登录用户保存，不能套用本预览的localStorage键。原生画布继续使用obscured处理遮挡，关闭弹层不销毁画布或重演剧情。

build-phone-layout.cjs从现行WXSS只读生成phone-native.css，phone-frame.css只处理手机框与本轮已确认的布局收紧。不能用本预览覆盖主对话刚更新的状态反馈与遮挡代码。
