# 星橙Q固定配色实样 · 鲜亮修正稿

版本：20261105-fixed-palette.2。日期：2026-11-05。品牌依据：20261105.3。

## 已确认与待确认

用户已接受R2三种、R3新增七种的正面造型，加基础Q共11种视觉形态。最新用户“确定”确认：13套固定配色保留，8套主推、5套放更多，所有形状通用。原13个颜色ID和既有使用权益均保留；具体新明暗色阶还须看实样，不据此授权接入、奖励变更或发布。

主推：星橙橙、珊瑚红、琥珀黄、薄荷绿、天空蓝、紫罗兰、玫瑰粉、栗棕。
更多：墨黑、暖橙、青绿、雾灰、奶油白。

上一稿用户指出“总觉得你的颜色偏浅，不知道为啥”“没有原始的橙色这么靓丽”。原因是非橙色亮部提浅、饱和度偏低，形成掺白感。修正稿以原始橙色的鲜亮程度为参照，主要提高彩色主体与亮部的色彩浓度，保留柔和体积。没有改变已确认的品牌橙色五阶明暗。

照片式材质、透亮玻璃与内部发光没有引入。这里是原生矢量的程序化角色配色，不是对第三方角色图片换色。

## 共用定义与冻结边界

依赖冻结的R2 `../星橙Q-形状扩展-R2-20261105/shapes.js` 和R3 `../星橙Q-形状家族-R3-20261105/family.js`。`palette.js`仅在相同SVG上替换身体明暗色与同色系深度层；身体、双眼、星芒的路径和位置均复用已接受的定义。品牌橙保持原有绘制像素。头像与动态伙伴用同一入口，不重画两套脸。

每套色包括5个身体色阶与一个深度层颜色；保留旧ID和oldHex作为对应记录，oldHex不直接等同于新的体积色阶。`previousRamp`仅用于前后对照，不是新增可选颜色，不参与默认渲染。

本地服务应以previews为根，避免遗漏R2/R3依赖。没有生成143套重复静态素材；当前共享定义可组合全部形状与颜色，但组合数量不等于新增宠物或奖励数量。

## 浅色待用户决定

奶油白保持浅奶油色身体和米白双眼/浅米黄四角星。原样小尺寸辨识较弱；候选方案仅加暖灰极细外沿，填色与路径不变。极细边仅有轻度改善，32px下仍较难辨认，不能视为已经解决。这是本轮适配比较，尚未批准为正式规则，不能擅自替换旧权益、删掉奶油白或改成深色五官。

配色预览默认原样，选择奶油白时显示两种对照，可切换细边候选看所有形状。深底检查帮助判断轮廓和材质，不自动解决脸与浅色身体的内在对比。
