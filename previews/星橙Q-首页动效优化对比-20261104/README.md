# 星橙Q 首页动效对比样张 · 2026-11-04

状态：独立样张，尚未接入小程序、同步云端或上传开发版。以当前已统一的星橙Q为基准，不引用旧版形象。

## 本轮改造

上一批六个常规手势已撤下。其问题是动作缺少目的、铺垫和意外，无法表达调皮与怪诞。本轮改为三段独立编排的默剧，保留安静时沉稳机灵的底色：

- 憋住，没憋住（9.8秒）：追着小浮尘看，努力憋住喷嚏，刚松口气却喷成方团子；愣住后恢复，并偷偷看人。
- 没人在看吧（10.4秒）：左右观察，偷偷起跳，落地摊成饼；发现被看见后慢慢撑回来，装作在认真看东西。
- 分身甩不掉（12.4秒）：软团子分出小分身，想甩掉却落到头上；吞回去后它又在身后偷看，最终被收回。

小分身的眨眼是近看彩蛋，首页小尺寸主要依靠分裂、落头、躲藏等轮廓变化表达。夸张变形只出现在剧情中，默认身体仍为原有圆团子。

## 保留与修复

原有零食、小行星、困倦与唤醒三段完整剧情的目标值、时间点和道具保留。当前首页还存在先用CSS、再换Canvas的接缝，以及部分缓动名称被简化的问题；候选统一Canvas绘制、恢复对应缓动，并用当前位置与速度承接切换。五官以当前形象为基础微调，保持原有橙色材质与四角星。

三段新剧情使用着地约束、面积补偿、抛物线起落、眼神预备和动作后的停顿。过渡中也保留形变，避免从饼或方团子突然切回圆球。
