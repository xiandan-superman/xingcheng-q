## 如何复用

保留当前相对目录结构。根目录安装依赖后，运行 `npm run check:avatars` 核对11种形状、13套配色与10档奖励的一致性；运行 `npm run check:avatar-artwork` 检查画稿。构建输入来自根目录previews中的R2/R3/R4/R5确认源。

移植组件时，应一并保留它引用的xingcheng-q-motion等组件、utils/animation-visibility、头像工具和对应素材；在目标页面JSON中注册组件。account/wardrobe和account/companions是原工程页面参考。

业务接入依赖原工程的services/student、services/answer-draft、services/data-revision等服务以及用户、成长和奖励接口，这些业务服务未纳入本次仅吉祥物的归档。需要提供growthGet、avatarSave、homeCompanionsSave、rewardSeen等接口，复用时按目标系统适配。云函数identity模块保存身份外观与奖励规则；mascot-features.reference.cjs为原profile-features.js中成长、头像、伙伴选择、奖励已读接口及必要辅助函数的摘录，配套achievement-counter.js保留权益计数依据，移植时仍需接入目标系统鉴权。后台catalog不代替完整奖励管理页面。
