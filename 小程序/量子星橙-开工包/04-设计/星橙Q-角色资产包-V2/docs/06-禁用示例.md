# 禁用示例

以下做法会破坏星橙Q的识别与 Bloub 动效语言：

1. 给角色永久增加手脚、耳朵、嘴、帽子或衣服。
2. 把问号、星环、提示点长期静止贴在球体表面；它们必须随状态进入和退场。
3. 用突然出现或消失替代连续形变和遮挡过渡。
4. 给配件使用另一套渐变、粗描边、玻璃高光、3D 塑料材质。
5. 同时播放两个以上角色动画，或让庆祝动画无限循环。
6. 无动作原因地拉伸圆球、单独漂移眼睛图层或使用与品牌无关的眼睛颜色。
7. 在加载、离线、权限等待中使用大幅庆祝或挥手。
8. 在小尺寸头像上叠加文字、徽章、红点并遮住眼睛。

视觉边界见 `assets/guidelines/主体与配件边界.jpg`。
