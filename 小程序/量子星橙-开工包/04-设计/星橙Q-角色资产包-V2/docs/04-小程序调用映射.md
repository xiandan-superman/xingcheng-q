# 小程序调用映射

## 推荐数据结构

```ts
type XingchengQState =
  | 'rest' | 'invite' | 'loading' | 'submitting' | 'correct'
  | 'needs-review' | 'attention' | 'empty' | 'offline'
  | 'notification' | 'transition' | 'daily-complete'
  | 'milestone' | 'waiting-access'

type XingchengQAccessory = 'none' | 'answer-writing' | 'wave-invite' | 'present-result'
```

## 资源解析

```ts
const assetRoot = 'https://cdn.example.com/xingcheng-q/v2'
export function roleAsset(state: XingchengQState, motion = true) {
  const ext = motion ? 'gif' : 'webp'
  const folder = motion ? 'gif' : 'static'
  return `${assetRoot}/assets/semantic/${folder}/xingcheng-q-${state}.${ext}`
}
```

## 页面映射

| 小程序区域 | 状态 | 建议尺寸 | 配件 |
|---|---|---:|---|
| 首页欢迎 | rest / invite | 96–144 rpx | 首次引导可 `wave-invite` |
| 答题输入 | focus | 88–120 rpx | 用户实际书写时可 `answer-writing` |
| 提交中 | submitting | 120–160 rpx | 无 |
| 单题结果 | correct / needs-review | 120–180 rpx | 无 |
| 今日完成 | daily-complete | 240–360 rpx | 结果静止后可 `present-result` |
| 空列表 | empty | 160–220 rpx | 无 |
| 网络/权限 | offline / waiting-access | 160–220 rpx | 无 |
| 消息红点 | notification | 56–80 rpx | 无 |

## 播放约束

- 同一屏最多一个角色播放动画，其余显示静态帧。
- 页面离开、进入后台、角色离开可视区时暂停或卸载动画节点。
- `daily-complete`、`milestone` 每次达成只播放一次，返回页面不自动重播。
- 可点击区域由业务按钮承担，不把角色本体做成无说明的按钮。
- 动画资源建议分包或 CDN 懒加载，静态兜底放主包。

配件不改变主体 state。业务先决定主体情绪，再叠加 accessory。例如填写答案为 `focus + answer-writing`；完成页为 `proud + present-result`。配件结束后设为 `none`，主体继续保持原状态。
