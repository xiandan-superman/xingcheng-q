# 情绪与语义状态映射

## 基础情绪

| ID | 中文 | 推荐场景 | 角色短句 |
|---|---|---|---|
| calm | 平静 | 首页、陪伴、默认头像 | 在呢 |
| focus | 专注 | 答题、分析、搜索 | 让我想想 |
| curious | 好奇 | 新内容、探索入口 | 发现新星 |
| happy | 开心 | 单题正确、轻量鼓励 | 这题对了 |
| proud | 自豪 | 阶段成果、连续达成 | 稳稳拿下 |
| confused | 疑惑 | 答案待复习、内容不确定 | 再看一遍 |
| sleepy | 疲惫 | 休息提示、低活跃 | 稍微休息 |
| gentle-reminder | 温和提醒 | 复习、学习提醒 | 该充星能了 |

## 产品语义状态

| ID | 触发 | 推荐位置 | 结束方式 |
|---|---|---|---|
| rest | 无任务 | 首页角落、个人页 | 循环或静止 |
| invite | 主动开始 | 首次进入、功能引导 | 用户操作后收束 |
| loading | 等待 0.6–8 秒 | 页面中心或按钮旁 | 数据返回后淡出 |
| submitting | 提交答案 | 答题卡中心 | 成功/失败状态接管 |
| correct | 答案正确 | 答案区附近 | 单次播放 |
| needs-review | 答案需复习 | 解析页 | 转入解析内容 |
| attention | 重要提示 | 弹窗、系统信息 | 用户确认后退场 |
| empty | 暂无内容 | 列表空状态 | 内容出现后退场 |
| offline | 网络断开 | 页面中心 | 网络恢复后过渡 |
| notification | 新消息 | 消息入口 | 单次播放，不循环 |
| transition | 页面转场 | 全屏过渡 | 下一页稳定后结束 |
| daily-complete | 今日任务完成 | 结果页 | 单次完整庆祝 |
| milestone | 连续天数/阶段达成 | 独立成果页 | 单次完整庆祝 |
| waiting-access | 权限尚未授权 | 授权说明页 | 授权结果接管 |

`correct` 与 `daily-complete` 不混用。前者确认一次答题，后者代表一天任务完成。
