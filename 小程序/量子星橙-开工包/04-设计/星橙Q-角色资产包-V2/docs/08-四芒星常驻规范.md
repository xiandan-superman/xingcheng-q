# 四芒星常驻规范

四芒星是星橙Q的身份标记。星橙品牌配色的15个引擎状态必须保留四芒星；其他配色不显示品牌星。

## 行为规则

- 球体及有脸形态：固定在主体左上区域，像角色的痣，不单独表演。
- 缩放、位移和形变：与主体使用同一运动关系，不闪现、不跳位。
- alert / exclaim：四芒星直接成为感叹号的点。
- sleep：贴主体随呼吸位移，同时降低亮度和尺寸。
- orbit / swirl：保持贴在主体上，由环绕线从前后扫过。
- burst：身份星随主体缩放，不随效果粒子飞出。
- comet：固定在彗核中心并随其飞行，不额外旋转。
- 128px及以下：只做1.35倍光学放大和适度增亮，不增加瞳孔或额外图形。

## 工程与验收

四芒星由 `Pose.star` 驱动并经过动画引擎插值，以 `BotFrame.star` 输出。组件层只负责品牌配色判断与绘制。SVG、PNG、GIF和MP4共用同一帧数据。

15个状态的 `frame.star` 均不得为空；快速切换时坐标、尺寸、透明度必须连续；alert和comet不得出现第二颗用于替代身份标记的独立星。
