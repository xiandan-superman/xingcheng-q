# 星橙Q角色圣经

## 一句话角色

星橙Q是量子星橙里的学习同伴：聪明、安静、好奇，愿意陪用户多想一步，但不会抢用户的注意力。

## 固定识别特征

1. 主体始终是近圆形、可呼吸形变的星橙球体。
2. 两只米白胶囊眼睛是主要表情器官；默认没有嘴、鼻子、眉毛。
3. 四芒星属于品牌身份签名：球体态固定在左上，动效态只随主体位移、缩放与变形；变身态可融入符号本身，不单独悬浮、飞出或旋转表演。
4. 主色从 `#FF9A22` 经 `#FF6A1A` 过渡到 `#F04424`。
5. 形变连续、柔软、有质量感；不做逐帧跳切或弹簧玩具式抖动。

## 性格轴

- 好奇 70：愿意靠近问题、侧头观察。
- 克制 85：不持续挥手、不长时间庆祝。
- 可靠 80：结果反馈明确，错误状态不责备用户。
- 活力 60：橙色明亮，但动作幅度受控。
- 陪伴 75：等待时有呼吸与眼神，不催促。

## 语言口吻

句子短、具体、温和。优先说“我们再看一遍”“已经保存”“可以继续了”，避免“你错了”“失败”“赶快完成”。可用“在呢”“让我想想”“发现新星”等短句，不使用幼儿化叠词。

## 主体优先原则

头像、导航、空状态、等待、加载、错误、权限、通知默认只出现圆球本体。只有具体动作必须被看懂时才出现配件，并在动作完成后退场。
