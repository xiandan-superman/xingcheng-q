# 动效与格式规范

## 动效规则

- 眼神先于主体形变 80–160 ms，形成“看到后反应”的感觉。
- 常规反馈 1.2–3.8 秒；完整庆祝可到 9.5 秒，只播放一次。
- 循环状态首尾必须回到同一完整球体姿态。
- 不对位置、缩放、旋转同时做大幅弹性动画。
- 配件与主体使用同一 ease-in-out 节奏，在 180–260 ms 内生长或退场。
- 小手直径为主体直径的 10%–15%；最多两只，不增加手指。
- 笔等道具用深墨色主体与单一星橙笔尖，不加高光贴纸或粗描边。

## 格式选择

| 场景 | 首选 | 说明 |
|---|---|---|
| 小程序常驻 | WebP/PNG | 体积小、渲染稳定 |
| 小程序关键反馈 | GIF | 320 px、20 fps，建议 CDN |
| 分享/视频 | MP4 | 512 px、30 fps |
| 设计与二次排版 | SVG | 基础情绪和标准头像 |

## 弱动效模式

系统开启“减少动态效果”、设备掉帧或网络较差时，直接显示对应 `semantic/static` 关键帧；不要播放低帧率替代动画。加载超过 8 秒时，角色回到 `rest`，文字继续说明状态。
