# 星橙Q四芒星常驻规范

本规范根据《星橙Q四芒星常驻优化方案（v3 修正版）》落地，采用文档开头“本轮修正”的原则作为最终口径。文档后文若出现星独立悬浮、飞出或自行旋转的早期示例，以本规范为准。

## 核心规则

四芒星是星橙Q的身份标记。角色使用星橙品牌配色时，15个状态都必须保留四芒星；其他配色不显示品牌星。

- 球体及有脸形态：星固定在主体左上区域，像角色的痣，不做单独表演。
- 缩放、位移和形变：星与主体使用同一运动关系，连续插值，不闪现、不跳位。
- 符号形态：星可以成为符号的一部分。例如 alert 的感叹号点直接使用四芒星。
- 彗星形态：星位于彗核中心并随彗核移动，不额外旋转或脱离轨迹。
- 爆发形态：身份星留在主体上随主体缩放；周围粒子属于效果层，不能替代身份星。
- 小尺寸：128px及以下只做1.35倍光学放大和适度增亮，不增加瞳孔或额外图形。

## 状态落位

| 状态 | 四芒星行为 |
| --- | --- |
| idle / wink / wide / notify | 固定在主体左上 |
| thinking | 随缩小后的主体同步位移和缩放 |
| alert | 成为移动感叹号的点 |
| exclaim | 成为主体上方提示符的点 |
| sleep | 贴主体左上，随呼吸位移，降低亮度和尺寸 |
| egg / hexagon / play | 贴在当前轮廓内部左上 |
| orbit / swirl | 保持贴在主体上；环绕线从前后掠过 |
| burst | 随主体一起缩放，不随粒子飞出 |
| comet | 固定在彗核中心并随其飞行 |

## 工程约束

四芒星由 `Pose.star` 驱动，经过动画引擎插值后以 `BotFrame.star` 输出。组件层只负责品牌配色判断和绘制，不再按状态计算坐标，也不再用主体裁剪路径决定星是否可见。SVG、PNG、GIF与MP4共用同一帧数据。

验收要求：15个状态的 `frame.star` 均不为空；快速切换时坐标、尺寸和透明度连续；alert和comet不得同时出现第二颗用于替代身份标记的独立星。
