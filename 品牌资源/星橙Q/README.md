## 小程序扩展

[已确认的头像形状与配色总览](小程序扩展/星橙Q-头像形状与配色.png) 包含11种形状、13套配色及奶油白A的小尺寸效果，10档奖励已接入工程。当前实现快照见 [小程序吉祥物实现归档](../../小程序/量子星橙-开工包/06-实现/吉祥物实现归档.md)；开发版上传与正式发布状态分别核对。总览PNG用于浏览；现行构建仍读取工程中的头像配置与确认源。

加载与宠物互动仍在 [独立样张](../../previews/星橙Q-三组交互样张-20261105/index.html) 中适配，尚未据此接入当前小程序。印刷、包装、毛绒等媒介是否采用扩展形态，按具体项目确认。

实体尺寸、真实三维模型、毛绒版型、面料色样与生产工艺尚待具体项目补齐。
